# IC-PBL 팀활동보고서

## 미팅 개요

| 항목               | 내용 |
|--------------------|------|
| 팀이름               | 찾고 (CakGo) — AI 기반 실내 물건 찾기 보조 서비스 |
| 일시               | 2026년 10월 15일 (Day 1 킥오프 미팅) |
| 참석자             | 팀원 전원 (Member 1: Detection, Member 2: Frontend, Member 3: Backend/Voice, Member 4: QA/Docs) |
| 문제해결과정       | 시각 약자 및 일상에서 작은 물건(열쇠, 안경, 지갑 등)을 자주 분실하는 사용자를 돕기 위해, 별도 고가 장비 없이 스마트폰 웹 카메라와 AI 객체 인식 및 한국어 음성 피드백을 결합한 보조 서비스 기획 및 1주 MVP 아키텍처 수립 |
| 본 미팅의 주요활동 | • 프로젝트 핵심 목표 및 1주 MVP 범위 확정 (스마트폰 카메라 UI + 객체 검출 모델 + 한국어 좌/중/우 음성 안내)<br>• 팀원별 모듈 담당 및 디렉토리 구조 확정 (`detection/`, `frontend/`, `backend/`, `voice/`, `tests/`, `docs/`)<br>• 모듈 간 병렬 개발을 위한 공통 API 명세(`docs/API_CONTRACT.md`) 및 7일 개발 계획(`docs/DEVELOPMENT_PLAN.md`) 합의<br>• YOLO 및 Grounding DINO 모델 비교 평가 환경 분리 및 저장소 초기화 |

## 진행 사항

| 항목                         | 내용 |
|------------------------------|------|
| 이번 미팅에서 한 일(활동 내용) | • 프로젝트 저장소 구조 초기화 및 핵심 아키텍처/컴포넌트별 README 작성 완료<br>• 프론트엔드-백엔드-모델 간 통신 규격 확정 (`POST /detect`, Bounding Box 픽셀 좌표 규격 등)<br>• `detection/` 폴더 내 `yolo/` 및 `grounding_dino/` 전용 작업 디렉토리 분리 및 실행 가이드 구성<br>• 7일 병렬 개발 로드맵 수립 및 일차별 통합 체크포인트(Day 1/2/3/5/7) 확정 |
| 이번 미팅에서 한 일(조치 사항) | • Git 저장소 안전 디렉토리 설정 및 `.gitignore`에 대용량 모델 가중치(`.pt`, `.pth`, `.onnx`), 가상환경, 개인 프라이버시 이미지 제외 처리<br>• GitHub 원격 저장소(`main` 브랜치) 초기 스캐폴딩 커밋 및 푸시 완료<br>• 모듈 간 의존성 병목을 방지하기 위해 목업(Mock) JSON 응답 기반의 독립 개발 체계 합의<br>• Git 브랜치 전략 확정: `feature/detection`, `feature/frontend`, `feature/backend-voice`, `feature/qa-docs` 분기 후 PR 기반 검토 |
| 논의 사항                    | • **모델 트레이드오프 비교**: 사전학습 YOLO(빠른 속도, COCO 80종의 소형 물건 한계 가능성) vs Grounding DINO(Open-Vocabulary 임의 텍스트 탐지 가능, 고용량/추론 지연 시간 증가) 간의 비교 벤치마크 방안 논의<br>• **모바일 통신 방식**: WebRTC 실시간 스트리밍 대비 초기 MVP에서는 브라우저 캡처 프레임 주기적 HTTP 전송이 구현 안정성과 모바일 호환성에 유리함을 확인<br>• **접근성(Accessibility) 가이드**: 저시력 사용자를 위해 고대비 색상, 큰 폰트/버튼, 화면 리더기 지원, 직관적인 한국어 위치 안내(좌/중/우 및 거리 표현) 필요성 강조 |
